FullBoard позволяет подключать собственный CSS для авторизованной панели и для
публичной страницы входа. Откройте **Настройки → Общие → Внешний вид**.

## Как это работает

| Поле | Где применяется | URL |
| --- | --- | --- |
| **CSS панели** | Все страницы под `/panel` после входа | `/panel/custom.css` |
| **CSS входа** | Только страница логина / 2FA | `/custom-login.css` |

Оба файла отдаются отдельно с `Content-Type: text/css` и
`X-Content-Type-Options: nosniff`. Они **не** встраиваются в HTML, поэтому не
могут выполнять скрипты и не вставляют разметку. Сохраните настройки и
перезагрузите браузер (панель добавляет query-параметр с хешем содержимого).

## Лимиты

- Максимальный размер: **64 КиБ** на поле (длина в байтах UTF-8).
- Байты NUL отклоняются.
- Живой предпросмотр (переключатель на вкладке «Внешний вид») временно
  вставляет `<style>` через `textContent` — это всё ещё не HTML — и
  снимается при уходе со страницы.

## Полезные селекторы

Панель — Ant Design 6 внутри layout FullBoard. Стабильные точки:

```css
/* Фон страницы */
.ant-layout {
  background: #0b1020;
}

/* Боковая панель */
.ant-layout-sider {
  background: #111827;
}

/* Основные кнопки */
.ant-btn-primary {
  background: #2563eb;
  border-color: #2563eb;
}

/* Карточки / таблицы */
.ant-card,
.ant-table {
  border-radius: 8px;
}
```

Предпочитайте классы Ant Design и обёртки layout, а не хрупкие
сгенерированные хеши. Избегайте `!important`, если только не переопределяете
тему, которая уже его использует.

## Страница входа

CSS входа загружается только на неавторизованной странице. Держите его
компактным — посетители видят этот файл до установки cookie сессии. Пример:

```css
body {
  background: radial-gradient(circle at top, #1e293b, #020617);
}
.ant-card {
  backdrop-filter: blur(8px);
}
```

## Советы

- Проверяйте и светлую, и тёмную тему (переключатель в шапке панели).
- Не вставляйте сторонний HTML или JavaScript в эти поля — принимается и
  применяется только CSS.
- Удалённые ноды могут получать те же поля через **Узлы → Управление →
  Настройки**, если токен ноды имеет admin-область.
