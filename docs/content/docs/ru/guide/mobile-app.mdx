Приложение We1ssBoard — нативное приложение для Android, которое работает через
API панели. В нём есть всё, что и в веб-панели: клиенты, инбаунды, аутбаунды,
маршрутизация, DNS, TG Web Proxy, узлы и хосты, все разделы настроек, API-токены,
логи, обновление Xray и панели, резервные копии базы. Оно поддерживает все языки
панели.

## Установка

1. Откройте на телефоне [последний релиз](https://github.com/WeIbSchatten/We1ssBoard/releases/latest)
   и скачайте `we1ssboard-android-<версия>.apk`.
2. Откройте файл и, когда Android спросит, разрешите установку приложений из
   этого источника.
3. В каждом релизе новый APK, подписанный тем же ключом, поэтому он ставится
   поверх старого с сохранением панелей и настроек.

## Подключение панели

<Steps>

<Step>
### Создайте API-токен

В веб-панели откройте **Настройки → Учетная запись → API Токен** и создайте токен
с областью доступа **Администратор**. Скопируйте его: он показывается один раз.
С токеном **Мониторинг** приложение будет только для просмотра.
</Step>

<Step>
### Добавьте панель в приложении

Введите адрес, который открываете в браузере, вместе с секретным путём,
например `panel.example.com:2053/abc`, и вставьте токен. Нужен действующий
HTTPS-сертификат; адрес `http://` тоже работает, но только в доверенной сети.
</Step>

</Steps>

Другие панели добавляются в **Настройки → Панели**, там же между ними
переключаются.

## Оповещения на телефон

**Настройки → Оповещения на телефоне**: приложение примерно раз в 15 минут
проверяет в фоне все добавленные панели, даже когда закрыто, и присылает
уведомление, когда Xray останавливается или снова работает и когда узел уходит
в офлайн или возвращается. Точное время проверки выбирает Android, поэтому
оповещение может прийти на несколько минут позже. Сервер push-уведомлений не
нужен: телефон сам опрашивает панели.

## Блокировка приложения

**Вход по отпечатку или лицу** спрашивает отпечаток, лицо или PIN устройства при
запуске и после 30 секунд в фоне.

<Callout>
  API-токены хранятся в зашифрованном хранилище телефона. Удаление панели из
  приложения стирает её токен, но саму панель не меняет. Если телефон потерян,
  отзовите токен в веб-панели.
</Callout>
